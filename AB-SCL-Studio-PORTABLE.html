Guía rápida · AB-SCL Studio

Declara entradas en VAR_INPUT y salidas en VAR_OUTPUT como BOOL. Después asigna cada salida exactamente una vez mediante expresiones con AND, OR y NOT, o usa un IF ... THEN ... ELSE ... END_IF; que asigne las mismas salidas en ambas ramas.

Las salidas calculadas deben depender solo de entradas declaradas y deben expresarse con hasta 8 ramas de 12 contactos. El motor prueba todas las combinaciones de hasta 12 entradas para confirmar la equivalencia del subconjunto admitido. No significa que pueda convertir todo SCL/ST ni que el código sea apto para una máquina real.

Exporta Proyecto KOP JSON para importar el resultado en AB-KOP Studio v0.1 y revisarlo visualmente.
